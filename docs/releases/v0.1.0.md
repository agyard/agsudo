# AG-sudo v0.1.0

首个公开版本，面向 Linux 上的 Agent 提权审批工作流。

包含：

- 无常驻 daemon 的 setuid helper、SQLite 请求状态和审计事件。
- `sudo` PATH shim、交互式 shell、标准流、退出码、信号和终端 job control。
- `review --tui`、JSON/NDJSON Agent CLI、异步请求、取消、过期和一次性执行。
- Claude Code 和 Codex 的 `agsudo integration install HOST` hook 接入。
- Linux amd64/arm64 release archives、安装脚本和校验文件。

安装 release archive 后执行：

```bash
sudo ./scripts/install.sh USER_UID
agsudo doctor
agsudo review --tui
```

`USER_UID` 是允许提交和审批请求的普通用户数字 UID。安装脚本不会修改
sudoers；它会把 `agsudo-helper` 安装为 root-owned setuid 程序。

首版只记录经过 AG-sudo 的提权请求。普通命令、root shell 内部逐条命令、
终端按键和命令输出不进入结构化审计。PATH shim 不能拦截绝对路径
`/usr/bin/sudo`、shell alias/function 或其他提权入口。

项目要求 Linux、Go 1.26.9+（源码构建）和 root 安装权限。完整的权限边界、
协议和 Agent 审批建议见 `docs/architecture.md`、`docs/protocol.md` 和
`docs/reviewer.md`。
