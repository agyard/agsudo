# AG-sudo v0.1.0

The first public release, built for agent privilege approval workflows on Linux.

Included in this release:

- A daemonless setuid helper, SQLite request state, and audit events.
- A `sudo` PATH shim, interactive shells, standard streams, exit codes, signals,
  and terminal job control.
- `review --tui`, a JSON/NDJSON agent CLI, asynchronous requests, cancellation,
  expiration, and single-use execution.
- Claude Code and Codex hooks installed with `agsudo integration install HOST`.
- Linux amd64/arm64 release archives, an installation script, and checksums.

After extracting the release archive, run:

```bash
sudo ./scripts/install.sh USER_UID
agsudo doctor
agsudo review --tui
```

`USER_UID` is the numeric UID of the non-root user allowed to submit and review
requests. The installer does not modify sudoers; it installs `agsudo-helper` as a
root-owned setuid program.

This release records only privilege requests routed through AG-sudo. Ordinary
commands, individual commands inside a root shell, terminal keystrokes, and
command output are excluded from the structured audit. The PATH shim cannot
intercept the absolute path `/usr/bin/sudo`, shell aliases or functions, or other
privilege escalation paths.

The project requires Linux, Go 1.26.9+ for source builds, and root privileges for
installation. See `docs/architecture.md`, `docs/protocol.md`, and
`docs/reviewer.md` for the trust boundaries, protocol, and reviewer guidance.
