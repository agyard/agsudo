# AG-sudo v0.1.3

This release removes what earlier versions kept only for compatibility. The CLI,
JSON output and state database change; nothing is migrated.

## Upgrading

Install both binaries from the archive as before:

```sh
sudo ./scripts/install.sh "$(id -u)"
agsudo doctor
```

The state database format changed. When the helper reports
`state database /var/lib/agsudo/state.db is damaged; delete it`, delete
`/var/lib/agsudo/state.db*` as root. Scripts that use removed commands or the
old JSON shape need updating.

## Simpler model

- Resuming means running the same command again: it reuses its request, runs
  it once approved, or reports its denial. `exec --request` is removed. Only a
  new `--reason` or `--context` replaces a pending request or answers a denial;
  the new request shows the one it follows.
- `--json` prints results directly; errors are `{"error":{"code","message"}}`.
  Events are `{sequence, type, actor_uid, request}`. Requests no longer carry
  `schema_version`, `detached`, `submitter`, `revision` or `owner_gid`, and
  context files no longer carry a hash.
- The environment is built from the request at execution instead of being
  stored in it, so review screens are shorter.

## Commands

- `events [--follow]` replaces `watch` and `audit export`.
- The guides are `agsudo exec --help` (also `sudo --help`) and
  `agsudo review --help`; `help --requester` and `help --reviewer` are removed.
  `--version` replaces `version`.
- Removed: the `status` alias (use `show`), `review --state` (people see pending
  and needs_human requests, scripts see pending ones, `--all` shows history),
  `--actor`, `--metadata` and `defer --summary` (use `--reason`).

## Review

- A reviewer's suggestion and earlier decisions appear right under the command,
  and the confirm line starts with `[suggested: deny]` (or approve) after a
  deferral.

## Fixes and internals

- A Ctrl-C during the first milliseconds of a wait no longer kills the helper
  before it can cancel the request.
- Housekeeping reads only requests that need it, request reuse is one indexed
  query, and reads no longer take the write lock.
