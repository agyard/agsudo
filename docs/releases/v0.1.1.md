# AG-sudo v0.1.1

本版改进 Agent 与人工审批体验，保留 daemonless 架构和 v1 JSON 协议。

- 帮助分为命令参考和工作流指南：保留 `COMMAND --help`、`help COMMAND`，
  Agent 指南统一为 `help --requester` / `help --reviewer`。
  移除顶层 `requester` / `reviewer` 伪命令；sudo 与等待提示使用新入口。
- `watch` 只保留事件相关的 `--session` / `--after`，继续支持 `review --watch`。
  `review` 不再静默忽略不适用的 `--after` 或覆盖冲突的 `--all --state`。
  `status` 收敛为 `show` 的别名，返回数据不变；审计固定导出 JSONL。
- 修复 `exec --request ''` 意外创建新请求；恢复请求时明确拒绝覆盖提交参数。
- `show` 与 TUI 补齐请求者 UID/GID、提交方式和执行环境；长表格按终端宽度
  截断命令与理由，保留完整请求 ID、状态和目标，管道输出仍完整。
  TUI 转人工确认更明确，拒绝 shell 时不再显示授权提示。
- 仓库与 Go 模块迁移至 `github.com/agyard/agsudo`，发布包继续支持 Linux
  amd64 / arm64。

已有用户解压对应架构的安装包后，从普通用户 shell 运行：

```sh
sudo ./scripts/install.sh "$(id -u)"
agsudo doctor
```

CLI 与 helper 一起升级，现有配置和数据库保留。脚本若使用旧角色帮助，改为
`agsudo help --requester` / `--reviewer`；事件订阅使用 `agsudo --json watch`，
列表筛选继续使用 `review`。自动化调用建议把 `--json` 放在子命令前。
